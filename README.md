## 📖 项目简介

**GameVault** 是一个纯前端的个人游戏收藏档案站。首页展示“我玩过的”与“我喜欢的”游戏，支持按平台、类型进行多维筛选和关键字搜索。点击卡片可进入统一模板的详情页查看单个游戏的详细介绍，并支持对游戏状态进行标记（喜欢/玩过）。此外，项目提供了管理页，支持用户手动添加新的游戏并持久化保存。

## 🛠 技术栈

- **HTML5**：语义化标签（`<header>`, `<main>`, `<section>`, `<article>` 等）
- **CSS3**：Flexbox / Grid 布局、CSS 变量、过渡动画、媒体查询（响应式）
- **JavaScript (ES6+)**：原生 JS、数组方法（`map`, `filter`, `find`）、DOM 操作、事件委托、URL 参数解析、`localStorage` 本地存储

## ✨ 核心功能 (MVP)

1. **双 Tab 切换**：首页无缝切换「我玩过的」和「我喜欢的」游戏列表。
2. **多维筛选**：支持按「平台」（PC/Switch/PS5等）和「类型」（RPG/动作/独立等）进行双维联合筛选。
3. **实时搜索**：输入关键字，实时过滤游戏名称。
4. **详情模板页**：点击卡片跳转 `detail.html?id=xx`，通过 URL 参数动态渲染不同游戏的详情数据。
5. **状态持久化**：详情页可切换“喜欢/玩过”状态，数据存入 `localStorage`，刷新不丢失。
6. **自定义添加**：在 `manage.html` 中可通过表单添加新游戏，包含必填校验，提交后数据存入 `localStorage` 并与初始数据合并展示。
7. **响应式适配**：手机端单列、平板双列、桌面三列布局，适配 375px 宽度无横向滚动。
8. **空状态提示**：当筛选/搜索无结果时，展示友好的空状态引导。
