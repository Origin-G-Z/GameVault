# 🎮 GameVault · 个人游戏档案与深度鉴赏库

## 📖 项目简介

**GameVault** 是一个纯前端的个人游戏收藏与深度评测分享平台。
项目采用了**沉浸式官网级首屏**设计，向下滚动即可无缝过渡到游戏库。支持多维筛选、实时搜索、状态持久化，点击卡片可进入深度长文评测与超清大图详情页。

## 🛠 技术栈

- **HTML5**：语义化标签、响应式 `viewport` 设置。
- **CSS3**：CSS 变量（浅色主题）、Flexbox / Grid 布局、媒体查询（Mobile First）、过渡与关键帧动画（`@keyframes`）、毛玻璃效果（`backdrop-filter`）、基于 GPU 加速的视差滚动。
- **JavaScript (ES6+)**：
  - **全局数据注册机制**：使用 `window.registerGame` 将分离的游戏数据注册到全局，无需本地服务器即可**双击直接运行**。
  - **DOM 操作与渲染**：使用 ES6 模板字符串进行高效的数据驱动视图渲染。
  - **数据持久化**：基于 `localStorage` 实现“喜欢”状态的全局同步。
  - **滚动交互优化**：监听滚动方向，结合 `requestAnimationFrame` 实现高性能的视差动画与吸顶栏智能隐藏。
  - **其他**：数组高阶函数（`map`, `filter`, `find`）、事件委托、URL 参数解析。

## ✨ 核心功能与交互亮点

1. **沉浸式官网级首屏**：
   - 满屏高清背景与深色渐变遮罩，极具电竞氛围。
   - 文字随滚动产生**视差位移与淡出动画**。
   - 底部“下滑探索”按钮平滑引导至游戏列表。
2. **智能吸顶筛选栏**：
   - 包含双 Tab 切换（全部 / 我喜欢的）、关键字搜索、平台/类型多维交叉筛选。
   - **智能隐藏**：向下滑动浏览游戏时，筛选栏会在第一排卡片即将离开屏幕时自动收起；向上滚动立即重现，不遮挡视野。
3. **卡片级快捷交互**：
   - 卡片右上角加入悬浮爱心按钮，点击直接收藏/取消收藏，无需进入详情页。
   - 鼠标悬停时，封面放大并带有光影扫过效果。
4. **精准锚点定位**：
   - 右下角悬浮按钮，点击可一键平滑回滚至“第一款游戏”的位置，并在到达时自动淡出。
5. **沉浸式二级详情页**：
   - 自动根据配置生成顶部 Hero 大图与渐变遮罩。
   - 侧边栏自动生成“文章目录（TOC）”，支持平滑滚动锚点。
   - 支持复杂排版（表格、引用块、高亮 Callout、插图）。
   - 左侧固定悬浮“返回游戏库”胶囊按钮（带弹动动画）。
