# 🎮 GameVault · 个人游戏档案与深度鉴赏库

## 📖 项目简介

**GameVault** 是一个纯前端的个人游戏收藏与深度评测分享平台，收录 **31 款**游戏、累计 **2077 小时**游玩记录（其中《反恐精英2》独占 1027 小时）。

项目采用**沉浸式官网级首屏**设计，向下滚动即可无缝过渡到游戏库。支持多维筛选、实时搜索、主题换色、状态持久化，点击卡片可进入深度长文评测与超清大图详情页。

> **核心特性：零依赖、零构建，双击 `index.html` 即可直接运行**，无需安装 Node.js、无需启动本地服务器。

## 🚀 快速开始

1. 下载或克隆本项目
2. 双击根目录下的 `index.html`
3. 完成 ✅

项目全程未使用 ES6 `import / export` 模块化语法，所有模块通过全局变量挂载在 `window` 上，因此**不会触发本地 `file://` 协议的 CORS 跨域限制**。

如果更习惯用本地服务器预览，也可以用任意静态服务器打开（非必需）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🛠 技术栈

- **HTML5**：语义化标签（`header` / `main` / `section` / `article` / `footer` / `figure`）、响应式 `viewport`、SEO `meta` 与 Open Graph 分享卡片。
- **CSS3**：
  - CSS 变量（浅色主题 + 可切换主色）、Flexbox / Grid 布局、媒体查询
  - 过渡与关键帧动画（`@keyframes`）、`cubic-bezier` 缓动、`will-change` 合成层优化
  - 毛玻璃效果（`backdrop-filter`）、渐变光晕、骨架屏 shimmer 流光
  - 基于 GPU 加速的视差滚动；`prefers-reduced-motion` 无障碍适配
- **JavaScript (ES6+)**：
  - **全局数据注册机制**：使用 `window.registerGame` 将分离的游戏数据注册到全局，实现"双击可运行"
  - **数据驱动渲染**：模板字符串 + 数组高阶函数（`map` / `filter` / `find` / `reduce` / `flatMap`）
  - **事件委托**：筛选区、空状态等统一在容器上监听，兼容动态插入的节点
  - **Web Animations API**：驱动"随机推荐"的卡片跳动，独立于 CSS `animation`，避免与入场动画冲突
  - **滚动性能优化**：`requestAnimationFrame` 节流 + `passive` 监听，实现视差、吸顶栏智能隐藏、阅读进度条
  - **数据持久化**：`localStorage` 保存收藏与主题选择
  - **其他**：URL 参数解析、`CSS.escape`、`matchMedia`、`Element.animate`

## ✨ 核心功能与交互亮点

### 1. 沉浸式首屏

- 背景**完全由 CSS 生成**（不再依赖图片），颜色实时跟随主题色，切换主题时整块首屏同步变色
- 五层视觉叠加：极光光斑 → 向前滚动的透视网格 → 地平线呼吸高光 → 缓慢扫光 → 四周压暗
- 文字随滚动产生**视差位移与淡出动画**
- 底部"下滑探索"按钮平滑引导至游戏列表

> 首屏滚出视口后会自动暂停动画（`IntersectionObserver`），系统开启"减少动态效果"时也会停止漂移，兼顾性能与无障碍。

### 2. 智能吸顶筛选栏

- 双 Tab 切换（全部游戏 / 我喜欢的）、关键字搜索、平台 / 类型多维交叉筛选
- **智能隐藏**：向下浏览到第一排卡片即将离开屏幕时自动收起；**向上滚动立即重现**
- 通过「方向阈值 + 时间防抖 + 滞回区间」三重机制，消除临界点来回抖动
- **类型标签折叠**：37 个类型按收录数量降序排列，默认只展示前 10 个高频类型，其余收进「更多」，可平滑展开 / 收起

### 3. 顶部导航栏

- 品牌入口 + **GitHub 仓库链接**（悬浮变黑并旋转图标）
- **迷你搜索框**：与页面内筛选框的搜索双向同步
- **主题色选择器**：5 套配色（靛蓝 / 翡翠 / 琥珀 / 玫红 / 海蓝），带文字标签、当前主题名与悬浮气泡提示
  - 主题色会**贯穿整站**：首屏动态背景、页面浅色底、边框、筛选面板、统计看板、卡片渐变、标签与页脚光晕全部随之变化
  - 页面底色由主色与浅灰按比例调和生成，保证仍是浅色主题且文字对比度不受影响
- **滚动状态**：向下滚动超过 80px 后导航栏加深、加分隔线与阴影

### 4. 卡片级快捷交互

- 右上角悬浮爱心按钮，点击直接收藏 / 取消收藏，无需进入详情页
- 鼠标悬停时封面放大 + 光影渐变
- **骨架屏**：封面图加载前显示 shimmer 占位，加载完成后淡入

### 5. 趣味与反馈

- **随机推荐**：右下角悬浮按钮，从当前可见卡片中抽取一款，卡片**原地上下跳动**并高亮（不重置筛选、不重建列表）
- **空状态**：搜索无结果时显示当前生效的筛选条件，并提供「清空全部筛选」「随机推荐一款」按钮；收藏夹为空时给出独立引导
- **精准锚点**：右下角按钮一键平滑回滚至"第一款游戏"的位置（自动避开导航栏与吸顶框）

### 6. 沉浸式详情页

- 自动根据配置生成顶部 Hero 大图与渐变遮罩
- 顶部**阅读进度条**，随滚动实时填充
- 侧边栏自动生成"文章目录（TOC）"，支持平滑滚动锚点
- 支持复杂排版：标题、段落、引用块、有序 / 无序列表、表格、高亮 Callout、正文插图、分割线
- 左侧固定悬浮"返回游戏库"胶囊按钮；右下角带旋转与展开动画的"返回顶部"按钮

### 7. 其他

- **SEO 与分享**：`description` / `keywords` / `author` 与 OG、Twitter 分享卡片标签；详情页会根据当前游戏动态注入标题与封面
- **页脚**：左侧品牌区，右侧返回顶部、技术栈标签与版权信息

## 🗃 数据说明

### 游戏基础信息

位于 `js/registry.js` 的 `window.GAMES` 数组中，每款游戏包含：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识，与详情页 `?id=` 及数据文件名对应 |
| `title` / `en` | 中文名 / 英文名 |
| `desc` | 卡片摘要 |
| `cover` | 封面路径，如 `./image/cs2.jpg` |
| `platforms` | 平台数组，如 `['PC', 'PS5']` |
| `genres` | 类型标签数组 |
| `rating` | 评分（0–10，一位小数） |
| `hours` | 游玩时长（小时） |
| `isFavorite` | 是否默认加入收藏 |

> 卡片上的评分与时长全部取自这里的固定数据，**不会随机变化**；顶部统计看板的"累计时长"由所有 `hours` 实时求和得出。

### 新增一款游戏

1. 在 `js/game/` 下新建 `your-game.js`，调用注册函数：

```js
window.registerGame({
  id: 'your-game',
  title: '游戏名',
  en: 'Game Name',
  tagline: '一句话点评',
  tags: ['标签1', '标签2'],
  blocks: [
    { type: 'h2', text: '一、基础信息速览' },
    { type: 'p', text: '正文内容，支持 **加粗** 与 *斜体*' }
  ]
});
```

2. 在 `js/registry.js` 的 `GAMES` 中追加对应的基础信息
3. 在 `index.html` 与 `pages/detail.html` 的脚本区各加一行 `<script src="./js/game/your-game.js"></script>`
4. 把封面图放进 `image/` 目录

### 支持的 block 类型

`h2`、`h3`、`p`、`quote`、`ul`、`ol`、`table`、`callout`、`image`、`hr`

## 📌 注意事项

- **注册函数大小写**：项目内游戏文件均使用 `window.registergame`（全小写），`registry.js` 中已通过 `window.registergame = window.registerGame;` 做兼容，请勿删除该行。
- **图片路径**：`registry.js` 中使用 `./image/xxx.jpg`。首页直接引用；详情页的封面经由 `renderer.js` 处理，可正确指向 `../image/xxx.jpg`。`image/` 中部分文件名含大写字母（如 `CS2.jpg`、`The_last_of_us_1.jpg`），修改路径时需保持大小写一致。
- **脚本加载顺序**：`registry.js` → `renderer.js` → `js/game/*.js` → 业务逻辑脚本，顺序不可颠倒。
- **浏览器兼容**：推荐使用 Chrome / Edge / Firefox 最新版。项目使用了 `backdrop-filter`、`color` 相关现代特性与 Web Animations API，IE 及较老的浏览器内核不支持。
- **主题色与首屏背景**：首屏背景由 CSS 渐变 + 极光 + 网格实时生成，会**完全跟随主题色**变化，不使用图片。`image/hero-bg.jpg` 仅作为社交分享（OG）缩略图保留。
- **首屏动效性能**：光斑使用 GPU 合成层（`will-change: transform`），并在首屏滚出视口时自动暂停；低端设备或开启"减少动态效果"时会退化为静态配色。
- **本地存储**：收藏状态存于 `localStorage` 的 `gv_favorites`，主题选择存于 `gv_theme`。清除浏览器数据会重置为默认值。
