## 📖 项目简介

**GameVault** 是一个纯前端的个人游戏收藏与深度评测分享平台。首页展示“我玩过的”与“我喜欢的”游戏，支持多维筛选、实时搜索与状态持久化；点击卡片可进入沉浸式的详情页，查看由独立模块驱动的深度长文评测与超清大图。

## 🛠 技术栈

- **HTML5**：语义化标签、响应式 `viewport` 设置。
- **CSS3**：CSS 变量（浅色主题）、Flexbox / Grid 布局、媒体查询（Mobile First）、过渡与关键帧动画（`@keyframes`）、毛玻璃效果（`backdrop-filter`）。
- **JavaScript (ES6+)**：
  - **模块化开发**：使用 `export` / `import` 拆分数据与逻辑。
  - **动态导入 (Dynamic Import)**：详情页通过 `import()` 实现游戏长文数据的按需加载（懒加载）。
  - **DOM 操作与渲染**：使用 ES6 模板字符串进行高效的数据驱动视图渲染。
  - **数据持久化**：基于 `localStorage` 实现“喜欢”状态的全局同步。
  - **其他**：数组高阶函数（`map`, `filter`, `find`）、事件委托、URL 参数解析。

## ✨ 核心功能与亮点

1. **数据与视图分离架构**：
   - `registry.js` 作为唯一的轻量级“数据库索引”，只包含首页展示所需的基础信息。
   - `renderer.js` 作为“渲染引擎”，将解析后的数据转换为标准 HTML 结构。
   - `js/game/` 文件夹下按游戏拆分文件，真正做到“一游戏一文件”，且只在进入对应详情页时才请求下载（性能优化）。
2. **双 Tab 切换与多维筛选**：无缝切换「全部游戏」和「我喜欢的」，支持按平台、类型交叉筛选。
3. **卡片级快捷交互**：卡片右上角加入悬浮爱心按钮，点击直接收藏/取消收藏，无需进入详情页。
4. **沉浸式二级详情页**：
   - 自动根据配置生成顶部 Hero 大图与渐变遮罩。
   - 侧边栏自动生成“文章目录（TOC）”，支持平滑滚动锚点。
   - 支持复杂排版（表格、引用块、高亮 Callout、图片插入）。
5. **贴心的细节体验**：
   - 左侧固定悬浮的“返回游戏库”按钮（带有弹性滑出动画）。
   - 滚动超过一定高度后浮现的“返回顶部”按钮（带有旋转展开动画）。
   - 首屏数据看板（自动统计游戏总数、累计时长与喜欢的数量）。
